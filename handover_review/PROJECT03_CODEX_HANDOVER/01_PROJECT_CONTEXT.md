## 策略的边界

经典简化双边做市用于持续产生交易负载：行情→参考价→买卖报价→库存偏移→撤旧与新单→处理拒绝/成交→更新库存。在异常行情、网关或状态不一致时停报。可以包含 spread、skew、position limit、quote refresh、rate limit、stale protection、kill。

不扩展为大量策略研究，不以模拟盈利、夏普率或成交概率验收。每侧默认最多一笔有效普通限价当日有效报价、默认 1 手，专用多手夹具验证部分成交。原生 Post-only、原子改价、双边原子报价和专业做市商待遇均不是默认能力。

## 系统范围与长期阶段

核心链路是 Market Data → Feed Handler → Market State → Strategy/OrderPlanner → Pre-trade Risk → OMS → Order Gateway → 外部柜台或自建模拟器 → 执行回报 → OMS/ExecutionLedger/PositionBook。它是逻辑链路，实际按事件异步运行，不要求一模块一线程或一服务。

M0 选型；M1 最小闭环且细分 M1A～M1F；M2 真实接口与 SMDP；M3 性能；M4 故障与恢复及四个案例；M5 七页工作台和交付；M6 按证据增加高级能力。现在仅有 M1A 实施授权，本轮只有交接授权。
