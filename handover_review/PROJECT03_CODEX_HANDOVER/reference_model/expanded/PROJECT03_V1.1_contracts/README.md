# PROJECT 03 V1.1 架构契约参考模型

这是一份独立测试材料，不是交易核心实现，不接 CTP 或 SimNow。
它验证报告中五项 P0 的部分状态规则和显式交错，不能证明真实线程、磁盘、SDK 或生产系统正确。

## 编译和运行

需要支持 C++20 的编译器，不依赖第三方库。Linux 示例：

```bash
g++ -std=c++20 -O2 -Wall -Wextra -Werror contract_model_tests.cpp -o contract_model_tests
./contract_model_tests
```

编译失败时不要运行旧二进制。程序检查不依赖 assert，测试失败返回非零。
execution_metadata.json 保存本次实际环境、选项、源码与输出 SHA256；model_results.txt 保存原始输出。

模型把每个方法调用视作已经串行化的一次状态转移，没有运行真实多线程。K01 枚举固定 C B I R 顺序中 K 的全部五个插入位置；O02 遍历六个事件的全部 720 个排列。没有声称穷尽所有真实并发或 CTP 回报排列。

K06 和 K07 的 PASS 表示测试发现了预期错误，不表示这两个错误模型是可用实现。其余测试的 PASS 表示该参考模型满足对应检查。

实际结果为 38 项通过、失败 0。没有基准测试、纳秒延迟数据、真实掉电测试、SDK 测试或账户连接。
