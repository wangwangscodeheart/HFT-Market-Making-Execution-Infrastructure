# 第十五小轮：受控回报交付记录

日期：2026-11-07。继独立 LocalSim 对端后加入同步、内存中的 `LocalReportDelivery`。

## 行为

调用方先让对端发生业务，再捕获返回的报告。捕获批次整体发布，容量不足或含非模拟来源/非报告事件时不发布任何编号。保存的报告不因交付而删除，可用明确编号选择交付顺序或重复交付。

每份捕获报告记录本地编号和对端生成版本；每次进入核心记录逻辑时间、实际 StepResult、原始输入序号与核心业务序号。编号不是交易所序号，时间不是实测延迟。来源标签只做实验输入筛选，不是身份认证；核心仍独立执行证据校验。

达到交付尝试容量或使用非法编号时，直接拒绝，不调用核心。核心拒绝的实际交付仍占用尝试记录。记录在进程内，重启丢失，不是 Journal、恢复证明或生产传输通道。
