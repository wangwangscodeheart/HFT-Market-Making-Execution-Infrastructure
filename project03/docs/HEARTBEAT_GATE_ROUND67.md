# 第六十七轮：核心拥有者心跳进入发送门禁

日期：2026-11-10。

LocalDispatchGate 增加 steady_clock 心跳预算，核心拥有者推进时更新。claim 与 TryCommitCall 在持有同一门闩互斥锁时重新采样实际时钟并检查年龄；领取成功不会替核心续心跳。年龄恰等于阈值仍有效，超过阈值或观察到时钟倒退即以 HeartbeatExpired 永久关门、推进停止代次。晚到 heartbeat 返回 Halted，不将门闩重开。

LocalAdapterSession 默认启用 5000ms，允许 1..60000ms，拒绝关闭或无界预算。独立门闩许可实验仍可显式使用零预算表示未启用，snapshot 标记 heartbeat_enabled，不能把该实验配置当作会话保护。构造可指定初始时点、领取/承诺可传观察时点仅用于确定性测试；实际适配器调用不传入伪造时点，在锁内读 Clock::now。

拥有型运行器在已接纳指令处理前后提供心跳；会话提交、结果处理、故障归并等入口也推进。空报告轮次可证明拥有者仍在运行，不要求每轮都产生订单；长时间核心操作结束后的心跳必须先检查旧期限，不能抹掉已经超时的间隙。心跳是拥有者活性，不是行情年龄、授权有效期、SDK 成功或订单风险结清证明。

过期阻断新增 claim 和 CallCommitted。已 Claimed 但未承诺的许可在承诺检查时撤回；已 CallCommitted 的许可仍保留到调用返回，心跳关门不能保证其不会随后进入对端。受限撤单和已接受订单的成交刺激不因心跳过期被丢弃，结果处理和故障归并仍可继续；这些操作也不能恢复新增发送资格。HeartbeatExpired 沿现有 LocalRuntimeFault 进入核心停报，不捏造 ReportLoss 或增加 lossGeneration。

当前没有新增独立看门狗线程。门闩在领取、承诺或拥有者心跳检查时判定过期；单独 snapshot 是观察，不主动推进过期状态。适配器空闲、没有待领取任务时不必周期唤醒；任何后续新单领取仍检查真实年龄。不能将此描述为超过阈值瞬间一定主动发出报警或自动撤净外部订单。

六项新增回归覆盖：阈值边界及承诺前过期、晚心跳不复活；正常心跳推进但已承诺调用过期后仍在途；倒退关门与禁用实验模式；真实线程 barrier 下的心跳/承诺交错；会话强制启用及无效配置释放租约；核心记录心跳停止时不伪造回报丢失。测试使用确定性时点，不以 sleep 模拟超时，也不宣称实际延迟指标。

范围：仍是固定本地双执行上下文；Writer/BridgeIO、完整故障/恢复矩阵、真实 SDK 和 TSan 尚未完成，M1C 尚未整体完成。

最终验证：2026-11-10-heartbeat-gate-debug / release 干净构建均通过 342 项测试、28,988 次断言，零失败。新增六项心跳回归经 CTest 与聚合执行通过；证据报告、页面逻辑与离线包检查通过。Release 当前源码与 40 份产物哈希核验通过；十四份既有功能输出在 Debug / Release 间、与第六十六轮最终版之间均逐字节一致。未验证 Linux、TSan 或长稳。
