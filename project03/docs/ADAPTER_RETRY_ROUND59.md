# 第五十九轮：核心会话租约与失败证据重试

日期：2026-11-10。

CoreLoop 增加独立于业务状态的原子附着标记；LocalAdapterSession 以 RAII 租约管理。租约在构造读取核心配置之前获取；同一核心的第二个会话立即拒绝，即使来自其他线程，也不先读取核心状态。构造失败自动释放；finish 后保留租约，直到会话析构并完成工作线程退出才释放。它防止重复会话，不使任意线程调用 CoreLoop::step 自动变得安全；核心仍须先于会话创建、后于会话销毁，并只交给其约定的拥有者调用。

新增 process_reports，每次接管一个适配器结果。它持有原始结果并按索引向核心逐条递交；只有 None 或 Duplicate 才前进。核心提交失败则保留当前及后续证据，关闭 EvidenceFailure 门闩并返回错误。后续 process_reports 返回 Blocked，必须显式 retry_reports 从保留位置继续。receive 旧手工接口在托管证据待重试时拒绝取走后面的结果，防止跳过失败项。

成功重试清除保留项，不解除门闩；再次空重试不调用核心，不增加订单或改变状态。报告队列中的后续结果须在前项成功后另行处理。旧 receive 接口仍用于受控手工检查，使用者取走后须自行承担证据保留责任；新的托管保证只覆盖 process_reports/retry_reports 接管的结果。内存保留不是耐久审计，会话析构也不持久保存未处理报告。

新增五项回归：重复会话在 finish 前后均拒绝、析构后可重新附着空核心；构造失败释放租约；其他线程重复附着拒绝；提交失败保留报告并阻断新命令，显式重试后独立查询对齐、重复空重试不改状态；第一项失败不得跳过到第二项。

边界：当前适配器只发送普通限价新单，这些报告重试验证订单接受证据，不宣称已覆盖并发成交报告全矩阵。尚未增加核心统一故障事件或恢复复位，EvidenceFailure 通过 gate 同步保持停领。四上下文运行器、Writer/BridgeIO、真实 SDK、TSan 仍未完成。

最终验证：2026-11-10-adapter-retry-debug / release 干净构建均通过 303 项测试、28,546 次断言，零失败。新增五项租约/重试回归经 CTest 和聚合执行通过。证据报告、页面逻辑及离线包检查通过，Release 当前源码与 40 份产物哈希核验通过；十四份功能输出在 Debug / Release 间、与第五十八轮之间均逐字节一致。未验证 Linux、TSan 或长稳。
