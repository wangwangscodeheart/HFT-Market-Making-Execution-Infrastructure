# 第五小轮：有来源的正常案例与双场景工作台

日期：2026-11-05。范围：M1A 同步内核、示例、测试及只读离线展示；非生产接入或完整故障注入台。

## 本轮交付

默认案例采用 FIX 官方 July 2020《Order State Changes》A.1.a 的正常接受/全部成交分支。来源与边界见 POSITIVE_CASE_SOURCE.md。

来源数量 10000，三次成交 2000、1000、7000；显式除以 1000 后，在本地 RB fixture 下委托 10 手，成交 2、1、7 手。价格、参考价、买开方向、账户、合约、日历、费用仍为本地设定。它是标准案例的派生业务输入，不是历史真实 RB 订单，不实现或模拟 FIX/CTP 传输。

保留撤单竞态契约回归。两案均共享既有 C++ CoreLoop / StepHarness；快照导出与批量文本 Demo 使用同一场景输入、不同推进方式，并对全部 14 步状态摘要逐步比对。

工作台新增案例选择、全事件导航、前后步、自动浏览离线快照、来源链接、数量缩放说明、实际四桶/冻结表、状态摘要查看和来源数量标注。图表纵轴随案例数量变化，不再固定为 3 手。自动浏览仅切换已导出的快照，速度不是交易速率。

撤下当前页面使用的手写 K 线：标准案例没有配套行情，不能将订单生命周期与无来源价格曲线拼成“真实场景”。保留禁用入口，等有明确来源的 OHLC/行情数据后接入。
