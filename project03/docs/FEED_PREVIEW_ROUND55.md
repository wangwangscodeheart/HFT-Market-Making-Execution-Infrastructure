# 第五十五轮：行情恢复实验可查看

日期：2026-11-10。

新增 `--feed` 导出及 `quote-feed.json`，使用显式完整快照模式，按十二步运行：正常报价、断线撤单、同订阅阻断、启动新订阅、拒绝旧订阅、收到新代次首帧、缺档撤单、合格新帧、过期撤单、新鲜快照、独立查询对齐、Kill 撤回。

导出包含原始快照的业务范围、来源、五档数组、有效档数、字段掩码、可选源时间和交易时段，以及逐帧 FeedHealth。原始数据来自 C++ 固定接口实验，绝非历史行情；接收计数也不是交易所逐笔序号。

报价轨迹页新增“行情断线 / 新订阅 / 资格恢复”场景。健康栏显示资格、订阅代次和接收序号；每步仍可查看实际核心调用、订单数量分区、原始输入和趋势图。最后一帧行情可保持 Valid，但核心已 Kill；页面明确说明行情资格不能解除交易限制。

新产物纳入构建状态和哈希清单，数据准备脚本检查十二步资格、阻断期间零新增调用、撤单后零占用、序号重启和独立查询对齐。离线包检查新场景来源与运行编号；Node 页面逻辑检查逐步导航、健康状态和切回旧场景清理。

新增 C++ 回归执行共享演示并重放十二帧，修改首帧所需深度时必须报告执行结果不一致。回放只验证给定输入和观察结果的自洽性，不认证输入来自真实交易所，也不证明记录未被整体改写。

本轮不改同步运行模型，不引入真实网关。浏览器原生视觉布局未验证，页面交互由 Node DOM 检查。

最终验证：2026-11-10-feed-preview-debug / release 均通过 278 项测试、28,304 次断言。证据报告、工作区及离线包的页面逻辑检查通过；Release 当前源码与 40 份产物哈希核验通过。十四份功能输出在 Debug / Release 之间逐字节一致，原十三份输出与第五十四轮保持一致。

预览：[独立离线报价轨迹](../evidence-local/2026-11-10-feed-preview-release/offline-preview/runner.html)，在场景选择框选择“行情断线 / 新订阅 / 资格恢复”。
