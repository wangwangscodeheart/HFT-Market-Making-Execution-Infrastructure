# 第五十三轮：有限档位行情资格层

日期：2026-11-08。对应方向复核中的 A02 行情主线。

新增 MarketSnapshot、MarketState、FeedHealth。固定上限五档，当前本地 profile 明确 required_depth；快照提供有效档位、买卖价量字段掩码、来源 epoch、订阅代次、本地接收计数与接收时间，以及可选不透明源时间。快照替换，不推导订单增删或逐笔成交；源时间不参与本地年龄计算。

行情资格包含 AwaitingData / Valid / Stale / Invalid / Recovering。检查档位、字段、价格区间与 tick、数量、档位排序、买卖交叉、时间与身份。当前代次无效快照使旧缓存失去报价资格，且高水位阻断旧序号或同序号修改重激活；诊断仍可查看旧快照。拷贝新快照失败前先撤销报价资格，不把潜在分配失败隐藏成成功更新。

断线或明确本地丢失进入 Recovering；旧订阅内再来新序号仍不能恢复。必须显式开始更高订阅代次，清除缓存后收到完整、及时的新快照。旧代次或其他来源不会污染新有效视图。本地接收计数不被当成交易所连续序号，跳号本身不声称发生上游丢包。当前可信源发生交易日变化时锁住当前日 profile，不能靠重新订阅或旧日数据重新报价；新日需新建并核对业务上下文，本轮不实现跨日恢复。

MarketTop 增加独立 subscription_generation，来源 epoch 与订阅代次不混用。策略新增 MarketState 入口，只读取合格顶档；允许新订阅的接收计数从一重新开始，拒绝返回旧订阅。原顶档入口保留用于已有明确的接口夹具；导出和输入比较同步携带订阅代次。

新增回归覆盖配置、缺档/字段、排序与 tick、年龄边界、重复不刷新、同序号冲突、时间倒退、旧订阅、断线重订阅、本地丢失、当前日边界以及策略联动。组合测试实际执行完整快照→策略→规划→核心→独立对端，行情失效后产生撤回意图并通过真实本地撤单回报释放订单占用。

边界：这是纯内存、固定本地 profile 的行情资格组件。LocalQuoteRunner 的常规 MarketPulse 入口仍是原顶档夹具，尚未统一改为完整快照/订阅/断线事件；本轮没有引入线程、SDK、原始报文解码或在线桥接，也不宣布 M1B 收口。接下来按 A02/A03 将新状态层接入运行器有序输入与重放，再核对剩余验收项。

最终验证：2026-11-08-market-state-debug / release 均通过 274 项测试、28,269 次断言；报告与证据检查通过。Debug / Release 十三份功能输出逐字节一致。相对第五十二轮，八份报价导出仅新增 subscription_generation 元数据，其余五份功能输出不变。
