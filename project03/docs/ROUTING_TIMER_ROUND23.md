# 第二十三轮：成交后开平重评与无新行情时的到期撤单

日期：2026-11-07。

## 修正开平重评

发现原规划器仅按价格与剩余数量判断是否保留活动报价。买侧成交形成多仓后，即使卖侧价量没变，原卖开报价也可能继续被保留，未执行优先减少已确认反向持仓的项目规则。

现在比较候选价格、开平桶和有效数量。若已确认持仓改变了开平路由，先撤原开仓单，取得终态后再规划平仓单。新增组合测试验证：买开成交一手；下一份同价盘口到达；原卖开撤销；替代卖平今冻结一手；平仓成交后核心和对端今多均回到零。另一侧未成交订单仍保留自己的风险占用。

候选路由计算会先把被比较订单自身的剩余平仓冻结临时算回可平量，仅用于只读比较，不修改账本。这样已经正确冻结持仓的平仓报价不会因“可平量被自己冻结为零”而被误改成开仓，也不会在目标量大于该桶可平量时反复撤换。

## 显式定时输入

新增 LocalQuoteTimer。运行器保存最后一份被接受盘口的接收逻辑时间；定时输入到达时，若盘口年龄严格大于策略 max_age，尝试撤掉现存报价，并返回 StaleMark。恰好到边界仍有效。没有接受过盘口时定时输入不产生核心调用；重复到期输入不创建新单。

新鲜、来源正确、序号更新的盘口可以再次经过策略和核心风控生成报价；旧盘口不会被定时输入自动复活。定时输入只做检查，不产生行情或刷新参考价。

这要求调用者显式投递定时事件。没有后台线程或系统计时器，进程无人驱动时不会自动撤单；逻辑步不代表毫秒或实际延迟。
