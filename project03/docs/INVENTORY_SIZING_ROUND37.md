# 第三十七轮：库存边界内的报价数量

日期：2026-11-07。

原简化策略仅在净库存达到上限时关闭增仓方向。若限额为 10、当前多头净库存为 9、配置报价量为 3，仍会给出买入 3 的目标。现在买侧数量受 limit-net 限制，卖侧受 limit+net 限制；随后按合约 lot_step 向下取整，低于 min_lots 则不生成该侧报价。仍先验证配置报价量与盘口价格符合合约规则。

例：净库存 +9、限额 10、配置量 3、手数步长 1，买侧目标改为 1，卖侧仍为 3。若最小量和步长均为 2，只有 1 手空间时不生成买侧；有 3 手空间时取 2，绝不向上凑量。

这只是策略目标的数量约束。核心风险准入、未决订单占用、先撤后建、成交证据与开平路由仍独立执行；不把买卖同时成交或净额抵消作为放宽依据。初始库存已超策略限额时仍允许缩减方向，不能声称一笔订单就能恢复到限额内。规划器对平今/平昨可用量的裁剪不在本轮改动范围。

新增回归检查正负库存临界值、只读策略不改变核心、规划意图数量，以及剩余空间按手数步长取整与不足最小量的抑制。
