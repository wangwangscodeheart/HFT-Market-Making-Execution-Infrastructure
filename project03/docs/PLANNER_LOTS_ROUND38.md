# 第三十八轮：开平路由裁剪后的手数规则

日期：2026-11-07。

策略目标符合手数步长，不代表它裁剪到可平仓量后仍合法。例：目标 4 手、平昨可用 3 手、步长 2，旧规划会生成平昨 3 手。现在选定开平桶后按合约 lot_step 向下取整，只有满足 min_lots 才生成提交意图，示例变为平昨 2 手。

保留项目既定的严格平昨优先：平昨仍有正数量但不足最小手数时，该侧暂停，不合并今昨、不跳到平今、不回退为开仓。这是当前本地规划策略，不代表交易所普遍规则，也不声称已经实现零碎持仓处置。没有可平仓桶时，开仓数量同样向下取整。

已有订单比较时仍加回自身冻结余量，避免重复撤单；数量需要调整时仅生成撤单意图，待实际终态证据后才能重建。部分成交可使剩余量小于最小报单量：成交本身仍正常记账，后续规划按规则比较余量并先撤后建，不将最小报单量误用于拒绝既有成交。

新增回归覆盖买卖两个方向的裁剪、冻结量比较不抖动、平昨零碎余量不跳桶，以及部分成交后只计划撤单。
