# 第四十九轮：统一运行器轨迹重放核验

日期：2026-11-08。

新增 verify_local_quote_trace，以给定配置构造独立 LocalQuoteRunner，按已记录帧的原始输入和逻辑时间重放。返回首个不一致的帧、已匹配帧数和分类错误，不返回可发送命令，也不修改原运行器。

逐帧比较核心摘要、模式、持仓和资金需求；策略目标及会话；实际核心调用载荷和完整 StepResult；订单观察值；完整对端查询身份、版本、订单资源分项与成交证据；待补齐/待交付、查询限制、丢失标记、收尾路径和可空对齐状态。核验调用载荷只接受当前运行器会产生的八类核心事件，其他类型不默认为相同。

八种导出场景增加统一核验，原有各场景重放和最终状态检查仍保留。新增观察值变更负例覆盖不同类别、首帧和后续帧的定位；覆盖空轨迹、错误配置、超过配置容量和有效短前缀。

边界：本入口核验已记录的帧前缀，不证明输入完整或配置身份，不检测未记录的纯拒绝尝试。尤其收尾实验的最终额外拒绝导致 cleanup_exhausted 变化，仍由原完整实验检查；不能仅凭帧核验通过就推断完整拒绝审计一致。不是耐久恢复、历史行情真实性证明或重新开放发送的授权。
