# 第五十四轮：完整行情进入报价运行器

日期：2026-11-10。

LocalQuoteRunnerConfig 新增可选 market 配置。开启后运行器持有 MarketState，核对业务范围、来源、价格边界、tick 与策略配置；旧 MarketPulse 顶档入口被拒绝，不能绕过资格检查。未开启新模式的历史夹具保留原路径。

完整快照及交易时段、订阅代次切换、断线、显式本地丢失成为四种有序输入，与成交、查询、停止共用外部顺序。合格快照进入既有策略、规划、核心和独立模拟对端；行情失效时撤回存量报价。断线后同代次新序号不能恢复；重新订阅后必须收到新代次的合格快照。定时输入检查年龄并撤回过期报价。

新模式逐帧记录 FeedHealth。内存回放重建 MarketState，核对完整快照、时段、订阅代次及健康状态；健康状态差异返回 RunnerState。这不是磁盘日志解析、恢复授权或持久审计。

新增组合回归覆盖断线撤单、新订阅从序号一重新开始、旧订阅拒绝、独立查询对齐、健康状态篡改定位、缺档撤单、旧入口拒绝、定时过期和显式丢失后不得同代次恢复。

边界：旧八种展示场景尚未迁移为完整快照输入；新路径首先由 C++ 组合测试验证。仍是同步、纯内存、单业务范围的本地模拟；没有接入真实行情协议、线程或耐久日志，也未据此宣布 M1B 全部完成。

验证：2026-11-10-market-runner-debug / release 干净构建均通过 277 项测试、28,301 次断言，零失败。两份证据报告生成通过，Release 当前源码与 39 份产物哈希核验通过。十三份功能输出在 Debug / Release 之间、与第五十三轮 Release 之间均逐字节一致；计时诊断不作字节一致要求。
