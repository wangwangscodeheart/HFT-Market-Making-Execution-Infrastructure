# 第五十轮：收尾实验包含拒绝尝试的重放核验

日期：2026-11-08。

新增 LocalQuoteAttempt 值记录与 verify_local_quote_experiment。记录原始输入、逻辑时间、返回码、前后帧数、停止/收尾耗尽标记及核心摘要。核验器按供应的尝试顺序重放，逐次比较这些结果；产生帧时复用上一轮完整帧比较，还检查帧的原始输入与本次尝试实际生成的输入一致。限制最多 4096 次尝试，配置帧容量继续生效。

收尾固定实验采集九次尝试、六个轨迹帧，包含触发普通容量停报、容量停报后新盘口被拒、最终收尾额度耗尽三次拒绝。C++ 导出新增 input_attempts 和 experiment_replay_verified；页面生成前要求九次记录、帧数轨迹及最终耗尽状态符合预期。旧帧前缀核验与完整实验检查仍保留。

采集在固定实验中进行，输入复制先于 step，记录向量预留九条。此实现不是通用运行时审计写入器；没有在日志满、异常或进程崩溃时保证审计耐久性。核验只证明供应的尝试序列与观察结果一致，不证明外部没有漏记输入，不把合法短前缀升级为完整性证书。

新增测试覆盖九次完整序列、三次拒绝及最后耗尽；改变拒绝结果、停止标记、耗尽标记、核心摘要、前后帧数、序号或时间时定位首个差异。另覆盖记录帧输入与尝试不一致、空尝试、错误配置和超出容量。

页面目前仍显示原三项拒绝检查，完整九次记录已在原始 C++ JSON 和生成数据中，尚未新增专门的页面表格。

Debug / Release 各 256 项业务测试、27,989 次断言，0 失败、0 跳过。十三份确定性输出在两个配置间一致；其中十二份与上一轮逐字节一致，收尾导出的所有原有字段及六帧内容保持一致，只增加尝试记录和核验结果。原有十一项诊断负控、十二项证据负控、四项包负控及全部页面逻辑检查通过。
