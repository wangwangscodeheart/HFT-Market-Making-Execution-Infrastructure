# 第五十一轮：输入尝试表接入工作台

日期：2026-11-08。

报价轨迹页新增固定实验输入尝试表。选择容量停报/收尾预留场景，可查看九次尝试的输入、返回码、前后轨迹帧数、尝试后的停报和收尾耗尽标记，以及原始 JSON。

点击产生帧的尝试，定位该帧；点击没有新增帧的拒绝，保留此前最后一帧，并明确说明它不是本次尝试的执行结果。尝试返回码和运行器状态独立展示，不覆盖轨迹帧中的历史状态。最终第九次拒绝可直接看见 cleanup_exhausted=true，即使该变化没有生成新帧。

切换场景、点击普通帧或前后步导航会清除尝试选择，避免把前一次拒绝标记套到其他帧。未采集尝试的其他场景明确显示缺少该序列，不用现有轨迹冒充完整输入审计。现阶段只有固定收尾实验采集九次记录，并不声称通用耐久审计。

Node 交互检查逐一点击九行，核对返回码、两个容量标记、原始载荷和所关联帧；三次拒绝必须显示没有新增帧，接受尝试必须显示新帧定位。检查最终耗尽及导航/场景切换后的清理。静态界面随构建归档，完整离线包也重复执行检查。
