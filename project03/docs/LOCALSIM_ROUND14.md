# 第十四小轮：独立本地交易对端

日期：2026-11-07。实现 M1B 的同步 LocalSim 切片；完整 M1B 尚未完成。

## 已实现

`p03_localsim` 独立维护订单、成交、四桶持仓、冻结和预算。它接收明确的请求值，不读取 CoreLoop 的实时账本，也不调用核心风控替自己作判断。返回报告后由调用者决定交付顺序，支持延迟成交及查询重放实验。

支持限价/数量/可平量/预算校验、部分成交、撤单、重复与冲突检测、容量上限，以及脱离内部状态的查询快照。LocalSimulator 与 LocalFixture 使用隔离的来源配置和经济成交作用域；不能混用提升核心证据。查询持仓/资金尚未进入核心恢复流程。

正常演示沿用已登记的 FIX Order State Changes A.1.a 分批成交分支，数量由 10000 按 /1000 缩放为 10，依次成交 2、1、7。它是标准案例的本地适配，不是 RB 历史行情回放。对端生成报告，核心实际消费；最终两侧今多均为 10，查询重放不重复记账。

## 验证

MSVC Debug / Release 各 150 项测试、25871 次断言，零失败。新增 10 项覆盖独立查询、正常成交、迟到成交与撤单竞态、对端独立拒单、六种持仓效果、重复及冲突、非法成交、容量、来源隔离和配置失败关闭。

正式证据目录为 `evidence-local/2026-11-07-localsim-sealed-debug` 和 `evidence-local/2026-11-07-localsim-sealed-release`。构建脚本封存源码、21 项产物及哈希，包含 `local-sim-demo.log` 和可执行文件；报告工具验证演示最终结果。此前 slice1 目录保留为中间构建记录，不作为本轮完整演示封存证据。

## 边界与下一步

预算只采用显式固定保证金和费用单位；平仓不返还历史保证金，属于保守实验预算，不是交易所资金试算或盈亏计算。没有随机行情、撮合排队优先级、真实市场冲击或延迟性能结论。

当前仍是单账户、单策略、单实际 RB 合约。尚未实现自动报价/Planner、交易时段、断连重连、受控运行器、并发、耐久日志及真实网关。FutureOperation::LocalSimulator 代表运行时启动请求，仍为 NotImplemented；新增库不等于已开放运行时能力。

工作台仍展示原有 M1A 离线案例，尚未加载 LocalSim 演示。后续先补受控脚本运行与报告交付记录，再接报价决策和前端，保留两侧独立观察值。
