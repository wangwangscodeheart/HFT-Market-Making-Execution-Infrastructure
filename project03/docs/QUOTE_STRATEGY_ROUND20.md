# 第二十轮：简化报价目标与本地组合闭环

日期：2026-11-07。

## 实现

新增 MarketTop、QuoteStrategyConfig、QuoteDecision 和 QuoteStrategy。策略输入是明确的账户/实际合约/交易日/持仓基线作用域、来源、模拟来源代次、序号、本地接收逻辑时间、最优买卖价量及健康标记。这里只接收完整最优档快照，没有增量订单簿重建或真实行情适配器。

有效输入生成最优买价上的买目标、最优卖价上的卖目标，默认一手。达到配置净仓上限时取消增加该方向风险的一侧目标；策略使用已记账净仓，订单最坏风险和总仓仍由核心检查。策略不互相净掉多空持仓，不计算收益、预测价格或宣称最优交易效果。

来源/作用域/代次不匹配，盘口过期、未来接收时间、价格相交、价量非法、非交易时段、核心 kill/未知暴露/亏缺或订单证据不完整时不给新目标，并返回 withdraw 请求。重复/旧序号及旧目标代次也停止本次目标生成。withdraw 是撤回报价目标的请求，调用方必须处理现存订单；它不是已撤单、已取消发送或风险已释放的证明。

策略只保存已接受的盘口序号和目标代次，不修改核心。生成目标后仍需规划，再逐笔提交核心。行情事件、策略状态和目标代次尚未并入 CoreLoop 的有序事件/持久化回放；当前是同步组合验证，不能宣称具备生产调度或持久化一致性。

## 组合验证

新增六项策略回归：有效盘口、重复序号/旧代次/错误 epoch、过期与异常盘口及闭市、库存抑制与平仓路由、kill 与缺失成交阻断、完整本地组合流程。

组合测试真实调用策略和规划器，核心接纳两侧订单后，独立 LocalSim 接单；买侧成交一手，卖侧撤单，再查询对端并执行查询完整性检查。最终两侧今多为一手，不从核心复制对端状态。

测试盘口 499/501 及数量明确属于接口单元夹具，不是公开行情或历史轨迹。原有标准 A.1.a 正常演示和固定故障场景保留原来源，不被这些接口输入替换。

证据目录：`evidence-local/2026-11-07-strategy-cycle-debug`、`evidence-local/2026-11-07-strategy-cycle-release`。

该中间构建各 175 项、26280 次断言通过。随后合并查询响应失败/无快照/QueryId 相关性回归，最终证据目录为 `evidence-local/2026-11-07-m1b-components-debug`、`evidence-local/2026-11-07-m1b-components-release`；当前源码以最终证据为准。
