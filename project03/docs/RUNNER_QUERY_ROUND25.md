# 第二十五轮：运行器内的暂扣回报与查询补齐

日期：2026-11-07。

## 实现

LocalQuoteRunner 新增三种显式实验输入：LocalDeferredFillInput 让独立对端成交并暂扣返回的 TradeReport；LocalHeldReportInput 按零基编号交付保留的回报，允许重复交付；LocalTradeQueryInput 请求对端完整同步查询，并可用明确的 omit_last_trade 故障参数删掉最后一行成交。

运行器维护有界保留回报和 pending_reports。pending 由这些明确暂扣的经济成交是否已出现在核心统一成交索引决定；查询记账后再交付推送会由核心返回 Duplicate。重复发起相同暂扣成交时，对端去重，不追加一份新的待交付风险。

存在已知 pending 时，市场输入不生成新目标、不提交新报价，尝试撤掉存量报价。对端已经完全成交的订单可能只返回撤单拒绝，核心仍保留原订单风险直到成交证据补齐；不把撤单请求或拒绝当成未成交证明。

查询先执行独立结构/数量/来源/请求相关性检查。缺行或查询身份非法时，不向核心投递任何成交、不清除 pending；完整查询通过后，成交逐笔进入核心。期间任何拒绝均保留已有状态和实际调用记录，不回滚真实对端成交。

每帧新增 pending_reports，保留两侧持仓分歧。核心调用预算增加对端最大成交行数，确保完整查询结果不会突破单输入预留上限。保留报告容量以对端最大成交数为界。

## 验证

新增四项组合回归：暂扣回报期间禁补单与不完整查询不记账；直接交付补齐及重复暂扣/交付去重；非法查询/编号不进入核心；原始输入重放保持两侧分歧、pending 和实际核心调用一致。

初次构建因 /W4 /WX 检出局部变量遮蔽失败，已改名修正；失败目录 `2026-11-07-runner-query-debug/release` 保留。最终构建目录为 `evidence-local/2026-11-07-runner-query-fixed-debug`、`evidence-local/2026-11-07-runner-query-fixed-release`。

## 限制

最终 MSVC Debug / Release 各 196 项测试、26587 次断言通过，零失败/跳过。四方清单一致，八项证据负控与三个页面的 Node 逻辑检查通过；七份既有导出诊断在两种配置逐字一致，页面数据已重新生成。新增暂扣/查询组合的重放由 C++ 用例验证，不把旧页面轨迹当成新组合证据。未验证原生浏览器布局、Linux 或真实时间性能。

这里的禁补单基于实验运行器明确知道自己暂扣了回报，不是对真实丢包的通用自动检测。pending 为零仅表示这些已知回报已通过推送或查询记账；它不是恢复证书、全账户查询覆盖证明、配置复位或 gate 重开资格。原有 kill、冲突与资金风险检查继续生效。

当前不实现真实断线、分页、重连会话、独立对端跨进程存活、耐久记录或生产发送。新组合由 C++ 用例验证；页面仍展示原五步报价与六步到期案例，尚无这一暂扣场景的独立页面轨迹。原导出程序已能识别新增输入类型及 pending 字段，避免将新输入误标为停止指令。
