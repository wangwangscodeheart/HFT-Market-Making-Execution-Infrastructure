# 第三十五轮：暂扣成交交付统一进入收件箱

日期：2026-11-07。

暂扣成交原先通过 LocalHeldReportInput 直接调用核心，绕过回报收件箱。现在释放时也经过有界收件箱：已有失败项时追加等待，不越过先到回报；提交失败则保留，显式 LocalRetryEvidenceInput 重试。保留的原始暂扣报告不被删除，成交是否已记账仍由核心成交身份判断。

成功处理已经记账的同一暂扣报告仍返回 Duplicate，经济成交只入账一次。普通查询继续遵守上一轮的背压规则。收件箱仍有容量上限，无法接纳时保留既有报告并锁住 delivery_loss；这不是耐久存储或无限接收承诺。

新增回归覆盖暂扣交付提交失败后重试、已有失败报告时不越序写核心，以及原始输入重放的一致性。既有停机迟到成交、查询补齐后重复推送场景继续作为回归。
