过去构建已归档 C++、脚本和原始 JSON，但工作台静态页面没有进入归档；历史数据可能被当前新页面展示。现在构建独立生成 ui-source-manifest.json，将 demos/round02 顶层静态文件复制到 ui-source，并将清单 SHA256 记入运行状态。构建结束时再次核对静态文件集合和内容，变化则拒绝该运行。
