# 第十七小轮：工作台两侧状态核对

日期：2026-11-07。入口仍为 `demos/round02/index.html`，新增面板独立展示 LocalSimulator 场景，避免与下方 LocalFixture 订单混为同一条业务流。

## 可见行为

页面上方新增对端今多、核心今多、缺失成交 H、确认未成交 L 四项读数，以及两侧持仓趋势。十行检查点可以直接选中，也可以用前后按钮切换；详情展示该检查点的原始 JSON、交付编号、输入序号和核心序号。核心未接收业务事件的观察帧以破折号展示序号，不伪造输入。

对端先成交时曲线分离；终态到达时核心保留两手 H；成交明细补齐后两侧收敛；重复成交保持持仓不变。曲线横轴是观察步骤，不是实测时间；数量为本地实验手数。

## 来源和生成

`prepare-local-replay.cjs RUN` 先调用 verifyRun 核验当前源码、归档源码、完成状态和产物哈希，再解析 C++ 的 `local-replay.json`，检查关键数量与守恒，生成 `local-replay-data.js`。页面展示 producer、run、构建配置和原始 JSON SHA256。

`report-m1a.cjs` 已自动执行此生成步骤和新增交互检查，兼容旧组件范围。页面不 fetch、不启动服务，不连接核心或柜台；可从文件系统直接打开。缺失或失败数据明确显示不可用，不生成替代轨迹。正常/竞态旧视图继续使用自己的来源标记。

## 验证与边界

MSVC Debug / Release 各 156 项测试、26052 次断言通过，零失败/跳过，导出的 C++ 状态和场景 JSON 一致。两轮报告均完成源码/产物校验、八项证据负控、新旧页面逻辑检查。页面当前使用 Release 运行的离线结果。

证据目录：`evidence-local/2026-11-07-replay-ui-debug`、`evidence-local/2026-11-07-replay-ui-release`。C++ 业务未修改；新增 Node DOM 检查覆盖十帧选中、详情、分歧、H 占用、收敛、重复、边界按钮、来源哈希及缺失/失败数据。旧工作台交互检查同时执行。

没有完成原生浏览器渲染/布局验收；Node DOM 检查不等于视觉测试。界面本身无交易控制能力，本轮没有实现 WebBridge、实时行情、自动报价、连接恢复、Journal 或性能测量。
